# Coastal Sorcerer（海岸术士）未实装白卡与全部蓝卡能力 Prompt 合集

> **遵循标准**：严格遵循 [卡牌与美术设计标准_Prompt规范.md](./卡牌与美术设计标准_Prompt规范.md) 的《杀戮尖塔 2》原版美术规范：两阶连通大色块、内部去黑线、彩色发光外描边、高饱和戏剧背景与 `85%` 满幅破框特写。
> - **未实装白卡**：共 **4 张**（`魔力打击 ManaStrike`、`凝滞的飞弹 StagnantMissile`、`法术防备 SpellWard`、`简短咒语 BriefIncantation`），并附赠最后 **1 张**未实装初始卡（`吸纳 Absorb`）。
> - **蓝卡能力**：共 **8 张**，全部采用**非人物站桩的创意概念 / 奇物机关 / 自然异象特写**，对标原版故障机器人的《循环》《散热片》与静默猎手的《步法》《跟踪》。
